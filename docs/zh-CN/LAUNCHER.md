# 启动与恢复契约

目录内入口、独立登记入口和设备操作是三个不同角色。打开向导不等于部署路由器或取得代理服务。

## 职责和兼容性

| 层 | 负责什么 | 不能据此推断 |
|---|---|---|
| 通用项目定位 | PROJECT 身份、启动文件、明确选择、取消和实际目录报告 | 必然有 Git、固定安装目录、固件品牌、代码真实性或完整载荷 |
| 宿主适配 | 控制台、物理目录身份、登记存储、文件夹选择器、桌面入口 | 必然有管理员权限、桌面会话或修改全局安全设置的权限 |
| 设备适配 | 只读能力探测、plan/apply、设备路径、运行时、备份和恢复 | 只凭型号或某个目录存在就证明受支持 |

通用结构检查位于 `scripts/lib/project-location.*`；文件系统实例身份和登记路径规则位于
`scripts/lib/host-launcher.*`。目录内入口不要求 `adapters/merlin` 或梅林专用操作存在。
可选功能在选择时检查，缺少实现会说明能力不可用，但不阻断核心菜单。

`bootstrap.sh` 通过受限标识调度可信、已安装的适配器。设备候选探测由各适配器的只读
`detect.sh` 提供，通用调度不依据品牌或持久化目录猜测。没有候选或有多个候选时要求明确选择。
当前真正实现的设备适配仍是 Merlin；合成适配器只证明调度隔离，不证明其它硬件受支持。
既有部署、回滚和自愈流程仍包含参考适配器集成，本次不声称所有既有设备流程已经完全解耦。

## 条件判断和恢复

| 情况 | 系统引导 |
|---|---|
| 没有 Git、不记得 clone 在哪 | 下载并完整解压发行包；用浏览器“在文件夹中显示”找到文件 |
| 本机无法下载 | 在可访问设备上校验完整包再离线转移；启动本身不需要重新下载 |
| 当前目录不同，路径有空格、中文或单引号 | 定位入口自身位置，保留原始路径，不任意删字符 |
| 原项目移走或删除 | 能使用系统选择器时打开选择器，否则输入路径；选择后重新检查 |
| 原路径被其它目录占用 | 不自动接纳新副本，要求重新明确选择 |
| 多份副本同时存在 | 目录内入口使用自身副本，独立入口使用明确登记的副本，不全盘扫描或随便猜 |
| 选错目录 | 解释身份/结构失败并允许再选；取消或输入结束不执行项目 |
| 核心启动文件不完整 | 重新解压或更新完整源文件，不静默替换到其它项目 |
| 可选操作没有安装 | 菜单和帮助继续可用；选择该操作时说明缺少的能力 |
| 无桌面、无选择器 | 使用终端入口和路径输入，不假设 GUI 程序存在 |
| 工具或写入权限不足 | 停止受影响的桌面设置动作，说明原因；保留目录内入口，处理后重试 |
| 登记路径是符号/硬链接、重解析点、类型不符或桌面名称被其它应用使用 | 保留原目标；换用空登记目录，或继续使用目录内入口 |
| 已有登记设置或位置修复进程正在运行 | 关闭该实例后重试；期间仍可使用项目目录内入口 |
| POSIX 登记锁遗留或所有权不明 | 检查报告的锁与进程，确认所有者已结束后才移除；否则换用新的空登记目录 |
| 初次设置中断，只有空目录 | 可安全重试；不属于项目的非空目录保留 |
| 已有项目登记缺少文件 | 从有效项目重新创建桌面入口，恢复复制的启动文件 |
| Linux 桌面要求信任入口 | 核对来源后按“允许启动”提示操作；助手不更改桌面的信任设置 |

Windows 使用 `.cmd` 与 PowerShell，macOS 使用 `.command`，Linux 使用 POSIX shell 和可选的
freedesktop 桌面入口。终端关联和来源确认仍由宿主决定，文件扩展名不能证明所有 GUI 场景已通过。
桌面集成不可用时，帮助和目录内启动仍是有效入口。

## 独立登记

登记目录包含项目所有权标记、复制的启动代码和 UTF-8 目标记录，记录路径及目录的文件系统实例身份。
Windows 使用卷/文件 ID 和创建时间；POSIX 使用设备/inode 及系统提供的创建时间。
它绑定普通文件系统实例，不是加密的代码身份。跨文件系统迁移可能改变实例身份，明确选择后重新绑定。

默认位置：Windows 的 `%LOCALAPPDATA%/HomeEdgeBootstrap/launcher`，macOS 的
`~/Library/Application Support/HomeEdgeBootstrap/launcher`，Linux 的
`${XDG_DATA_HOME:-~/.local/share}/home-edge-bootstrap/launcher`。登记不会编辑 PATH 或 shell profile，
也不保存路由器密码、订阅 URL 或 controller 密钥。

创建快捷方式是用户选择的本机写入。替换前检查标记、叶路径类型和链接，复制启动代码后才生成桌面入口。
部分失败不会报告就绪，应从源目录重试。位置修复使用临时记录和 rename；多文件安装不声称具有完整的
断电原子性，不会为恢复而删除无关非空目录。

设置和独立入口的位置核对共用 `.home-edge-launcher.lock`。Windows 使用独占文件句柄，进程退出后由
系统释放；POSIX 使用带所有者记录的目录锁，遗留或未知锁不会自动回收。打开菜单前释放锁。
每个登记文件使用同目录临时文件和 rename 发布，并发写者不能混合不同副本。

POSIX 遗留锁可先执行 `cat "<报告的锁目录>/owner"`，再用 `ps -p <记录的PID>` 核对进程。
独立确认拥有该锁的设置/启动进程已经结束后，仅执行 `rm "<报告的锁目录>/owner"` 删除其所有者记录，
再用 `rmdir "<报告的锁目录>"` 移除空目录。不要删除未知内容或活跃进程的锁。
所有权不明时，使用 `sh "<项目目录>/start.sh"`，或选择新的空登记目录。

高级用户可为 PowerShell helper 指定 `-DestinationDirectory` / `-LauncherDirectory`，或为 POSIX helper
指定 `--directory` / `--launcher-dir`；普通菜单无需学习这些参数。删除桌面图标只移除便利入口，不会删除
项目目录、路由器安装或保留的操作员状态。

## 验证边界

发行 ZIP 与 tar 归档将 `.sh`、`.command` 入口记录为 Unix 0755，即使在 Windows 上构建也如此。
源码启动入口也保留 Git 可执行模式。这些权限不能证明原生桌面关联或来源确认界面已经验收。

fixture 覆盖非项目当前目录、原始路径、结构身份、目录替换/迁移、无效选择、可选操作缺失、快捷方式冲突、
链接和中断设置。Linux GIO 对测试专用的 `Terminal=false` 入口执行原生解析，不能据此声称每种桌面的
终端选择或信任 UI 都已验收。宿主 CI 和归档检查补充这些证据；原有源码、供应链、真实设备及兼容性声明
边界继续适用。
