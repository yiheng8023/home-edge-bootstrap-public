# Home Edge Bootstrap

[English](README.md) | 简体中文

最短路径：[快速开始](QUICKSTART.zh-CN.md)。

发布下载：[GitHub Releases](https://github.com/yiheng8023/home-edge-bootstrap-public/releases) ·

[发布契约](docs/zh-CN/PUBLIC_RELEASE.md)。

Home Edge Bootstrap 是面向家庭与中小组织网络边缘的能力驱动型启动、恢复与韧性框架。
它将未准备好的边缘网关渐进式引导为可观测、可恢复、可自愈的代理路径，同时把必须由人
判断的事项保留为明确边界。

当前已实现的参考适配器面向运行官方 Asuswrt-Merlin 的华硕路由器，并使用
ShellCrash/ShellClash 与 Mihomo 兼容运行时。这是首个已实现适配器，不是永久架构边界，
也不代表该适配器已经取得“已验证”成熟阶段。Windows、macOS 与 Linux 是当前声明能力
边界内的操作宿主机系列。

框架复用成熟代理运行时及其既有管理界面，不重复实现代理核心或仪表盘。未来可通过独立
适配器接入其他设备、固件和运行时系列，但必须先明确并验证相应能力、安全、恢复、证据和
维护契约。

## 首次进入：取得文件、打开向导、保存入口

**不需要先安装 Git，也不用先打开终端或记住项目目录。** 已有 clone 或完整解压目录时直接看第 2 步。

### 1. 取得完整项目

| 你的电脑系统 | 下载哪个包 | 解压后打开哪个文件 |
|---|---|---|
| Windows | [ZIP 启动包](https://github.com/yiheng8023/home-edge-bootstrap-public/releases/download/v0.1.8/home-edge-bootstrap-v0.1.8-offline.zip) | 双击 `start.cmd` |
| macOS | [tar.gz 启动包](https://github.com/yiheng8023/home-edge-bootstrap-public/releases/download/v0.1.8/home-edge-bootstrap-v0.1.8-offline.tar.gz) | 双击 `start.command` |
| Linux | [tar.gz 启动包](https://github.com/yiheng8023/home-edge-bootstrap-public/releases/download/v0.1.8/home-edge-bootstrap-v0.1.8-offline.tar.gz) | 打开 `start.sh`，可选择“在终端运行” |

下载完在浏览器的下载记录中选择“在文件夹中显示”（Windows 常用 **Ctrl+J**），再**解压整个包**。可将解压文件夹保存在“文档”或自己的常用目录；不限定盘符、用户名或路径。不要在压缩包窗口内运行，也不要只取一个脚本。安装只需对应系统的一种包；校验文件和复制即用的校验步骤见 [发布说明](docs/zh-CN/RELEASE_NOTES.md)。

下载条件不足时，可以在可访问发布页的设备上下载并校验完整包，再离线转移。clone 也是有效取得方式，但不是普通用户的前提。上述系统是操作电脑；离线运行载荷仍面向当前参考设备适配器，不代表已支持所有设备架构。

### 2. 打开并核实目录

在解压或 clone 的文件夹里，找到同时包含 `PROJECT`、`README` 和 `scripts` 的那一层，打开上表的入口。入口自动定位自身所在目录，核实项目标记与启动所需文件，并显示实际使用的 `project_dir`；不依赖当前终端目录，不要求 `.git` 存在。它检查的是启动结构，不是代码签名或整仓安全认证。

macOS 若系统要求确认来源，核对下载来源后按系统提供的“打开”流程处理；如果执行权限没有保留，可通过终端运行。Linux 不同桌面的脚本关联不同：没有“在终端运行”时，打开终端，输入 `sh `（末尾保留空格），把 `start.sh` 拖进去，再按回车。macOS 也支持这个替代入口，均无需先 `cd`。

菜单默认中文；菜单内输入 **L**、**language** 或 **9** 即可切换英文。需要非交互参数时，可使用完整路径，例如 Windows 的 `& "实际项目目录\start.cmd" -Language en`，或 macOS/Linux 的 `sh "/实际项目目录/start.sh" --lang en`。可将文件拖入终端自动填入路径，不必手抄。Windows 用户也可以在项目文件夹的资源管理器地址栏输入 `powershell` 并回车，终端会直接位于该目录。

### 3. 以后从固定入口进入

三种系统均可在向导里选择 **8：创建或更新本机桌面启动入口**。也可从文件夹直接打开对应的 `create-desktop-shortcut.cmd`、`create-desktop-shortcut.command` 或通过 `sh` 运行 `create-desktop-shortcut.sh`。

独立入口保存你选择的项目位置和目录实例身份，启动时重新检查；项目移动、删除、注册记录失效或旧路径被另一副本占用时，会引导重新选择，并再次核验。可用时使用系统文件夹选择器，否则提示输入路径；取消或输入结束不会执行项目。多个 clone 可以并存：目录内入口使用自身副本，独立入口使用你明确登记的副本，不进行全盘扫描或随便选择。Linux 若桌面要求“允许启动”，核对入口后按桌面提示完成；无桌面环境仍可使用终端入口。

登记目标与缓存启动文件均匹配当前副本且桌面指向该登记入口时，桌面设置报告 `shortcut_state=reused`。更新另一项目自有目标、不完整登记或已变化的缓存启动文件，须先输入 **REPLACE** 再输入 **APPLY**。无所有权的存储与无关桌面文件不能覆盖。此操作更新本机入口，不是重装路由器。

没有 Git、不能联网、没有桌面、缺少工具/权限、可选功能未安装等情况，按 [条件与恢复说明](docs/zh-CN/LAUNCHER.md) 选择可行路径。核心入口不要求华硕或梅林适配器存在；设备操作需要相应实现和目标能力，条件不足时说明缺项。打开菜单不会自动部署、更新运行时或改路由器；可写操作沿用明确确认和原有恢复流程。

### 帮助、语言与已有安装

在主菜单输入 **H**、**?**、**help** 或 **6** 查看本机帮助：菜单动作、前置条件、确认、恢复与文档路径。输入 **L**、**language** 或 **9** 即时切换中英文。切换保留路由器目标与所选会话，只在本次 TUI 会话有效，不联网、不写全局设置。**0** 退出。

选择 **1** 开始或接续。系统对所选路由器和项目路径进行新的只读探测，区分 `installed`、`partial`、`not_installed` 和 `unknown`。发现已有项目内容时，默认诊断并复用保存的会话。`installed` 只表示可识别的项目自有内容存在，不代表运行时健康或网络／生命周期完整验收；单独安装 ShellCrash/Mihomo 不等于安装本项目。只有正面确认项目不存在才允许首次安装；所有权未知、外来内容、链接或探测失败／格式异常时，停止部署并要求审查。

需要刷新项目自有内容时，主动选择 **R**，审阅目标、计划和 `<项目路径>.prev` 备份，再精确输入 **REPLACE**，随后输入 **APPLY**。旧 `.prev` 备份可能被替换。此操作使用仅项目部署范围，阻止运行时／core 载荷替换，但可能更新项目受管集成与配置，不是完整运行时回滚。实际写者在取得锁后重新检查所有权。运行时替换与 core 替换仍须分别显式选择；仅替换运行时会保留已有 core，除非另行指定 `ReplaceCore` / `BOOTSTRAP_REPLACE_CORE=1`。

向导在菜单／动作切换及重要工作前后重新检查当前项目结构、目录实例和所需工具可用性。已知条件退化会阻断受影响动作并提供恢复指引，**H**、**L** 与 **0** 仍可用。这是事件触发的检查，不是后台守护，也不声称识别全部未知故障。支持的恢复路径见启动契约。

## 从这里开始

选择或刷写路由器前，先按准确型号和硬件修订版核对
[Asuswrt-Merlin 官方支持型号页](https://www.asuswrt-merlin.net/about)，再到
[官方下载页](https://www.asuswrt-merlin.net/download)确认当前确有对应构建；型号专属的
手册、原厂固件和恢复工具以[华硕官方下载中心](https://www.asus.com/global/support/download-center/)
为准。华硕仍提供该型号资料，并不等于 Asuswrt-Merlin 当前仍支持。修改设置前先阅读
[路由器基线](docs/zh-CN/ROUTER_BASELINE.md)。

刷写步骤遵循[梅林官方安装指南](https://github.com/RMerl/asuswrt-merlin.ng/wiki/Installation)；本项目
不会下载或刷写路由器固件。项目官网不可达时，使用官方
[SourceForge 发布区](https://sourceforge.net/projects/asuswrt-merlin/files/)，或梅林官方下载页当前
列出的其他官方下载入口。第三方社区或支持网站可能只面向某个国家或地区，也可能分发改版固件；
不假定其他国家或地区存在对应站点，也不要把它当作官方来源。

三种系统的下文相对脚本示例均适用于已核实 `project_dir` 的项目内终端；否则使用各脚本完整路径。
启动或退出向导不会改变原终端当前目录。普通使用继续通过菜单完成。

高级命令入口（可选）：在文件资源管理器中打开解压后的项目文件夹，点击地址栏输入 `powershell` 并回车，终端会直接位于正确目录。然后运行：

```powershell
.\start.cmd -Language en
.\start.cmd -Help
```

如果已经打开了别处的终端，使用完整路径，不要假定当前目录：

```powershell
& "C:\你的解压文件夹\start.cmd"
```

```sh
sh "/你的解压目录/start.sh"
```

将示例路径换成实际解压目录，或直接将启动文件拖入终端自动填入路径。开发者仍可 clone 仓库；普通使用者不需要先安装 Git。

在 macOS 与 Linux 上，本地验证需要 Python 3。可使用 `python3`；仅当 `python` 指向 Python 3 时才可使用 `python`。不支持 Python 2。

## 完成标准

只有目标自身的证据同时满足以下条件，才可将该目标视为可用：

- 已具备必需的宿主机、SSH、固件、持久化存储、shell 与运行时能力。
- 路由器基线不存在尚未处理、也未由操作者明确接受的行动项。
- 任何写入前，dry-run 计划都已明确目标、受管路径、备份和回滚路径。
- 运行时已消费通过校验的订阅或配置，且没有暴露订阅凭据。
- 健康检查能够发现并查询运行时，而不是依赖固定 controller 端口。
- 在理解路线选择与回退行为之前，自愈保持 dry-run。
- 客户端侧检查确认了预期拓扑，没有把终端代理静默当成路由器路径证据。
- 声明目标及已接受边界的最终安装门禁通过。

合成 fixture 证明的是脚本行为，不会认证具体路由器、固件构建、服务商或网络。应用变更前
请阅读[兼容性](docs/zh-CN/COMPATIBILITY.md)。

## 引导式 TUI

零新增依赖的 TUI 是常规交互入口。它是编号式向导，不是仪表盘：路由器固件、ShellCrash、
软路由和终端代理继续使用各自管理界面。向导调用已有诊断、启动、离线恢复、回滚和支持包
导出脚本，不复制这些脚本的状态机。

引导按以下顺序渐进执行：

1. 不连接路由器，先检查本机前置条件与文档。
2. 声明目标，再通过 SSH 执行只读能力探测。
3. 审查 `--dry-run` 部署计划，包括备份与回滚信息。
4. 只有计划可接受时，才输入精确令牌 `APPLY`。
5. 先验证运行时和客户端拓扑；只有确实准备开启真实自愈时，才输入精确令牌 `ENABLE`。
6. 只有确实准备执行提示中的回滚时，才输入精确令牌 `ROLLBACK`。
7. 生成脱敏支持包后，逐个检查文件，再决定是否共享。

EOF、中断、无效输入或任何不符合要求的确认内容都会取消可写动作。

## 架构与产品边界

框架将通用控制契约与适配器实现分离：

- 通用层定义任务入口、能力检查、plan/apply 分离、备份、回滚、恢复、秘密处理、证据和
  收官行为。
- 适配器把这些契约映射到具体设备、固件、文件系统、服务管理器与运行时组合。
- 成熟第三方运行时继续负责流量处理和自身运维界面。
- 回退路径保持运维独立；回退成功不能证明路由器路径工作正常。

| 领域 | 当前公开范围 | 边界 |
| --- | --- | --- |
| 已实现参考适配器 | 运行官方 Asuswrt-Merlin 的华硕网关 | 仅为首个实现；不是永久产品边界，也不是“已验证”成熟度声明 |
| 代理运行时 | ShellCrash/ShellClash 与 Mihomo 兼容运行时 | 项目负责协调并验证路径，不替代运行时或其仪表盘 |
| 操作宿主机 | Windows、macOS 或 Linux | 不同宿主机的命令与可用能力不同 |
| 离线恢复 | 源码 checkout；存在时另用经过独立校验的离线发布物 | 源码 checkout 不代表已经包含运行时载荷 |
| 回退路径 | 独立软路由或端点回退 | 用于保留恢复访问能力，但不会认证路由器路径 |
| 自动化 | 对安全、边界明确且可验证的动作自动化 | 刷固件、购买服务、凭据、信任判断与最终接受仍由人负责 |

详见[架构](docs/zh-CN/ARCHITECTURE.md)、[无代理前置约束](docs/zh-CN/NO_WALL_BOOTSTRAP.md)
与[威胁模型](docs/zh-CN/THREAT_MODEL.md)。

## 适配器与支持模型

适配器成熟度和目标支持分类是两个独立维度：

- 适配器成熟度描述实现责任与证据：外部集成、实验性适配器、社区维护适配器或已验证适配器。
- 目标支持分类描述适配器对某一目标的判断：`supported`、`supported_needs_manual`、
  `accepted_modified`、`unknown` 或 `unsupported`。

当前 Merlin 实现是已实现参考适配器；这一角色不等于取得“已验证”成熟阶段。公开兼容性
矩阵当前只包含政策声明与合成 fixture 证据，现场证据集合有意保持为空，因此其中列出的目标
路径保持为 `unknown`，直到目标专用证据能够建立其他分类。

未来适配器在具备明确维护者，以及边界清晰的能力、安全、恢复、证据、维护、迁移和项目退出契约，
并具备合成 fixture、回滚行为、不含敏感信息的诊断、
双语操作说明和与支持声明相匹配的证据路径之前，应保持为外部实现。接纳与成熟度调整由维护者
通过审查决定；受欢迎程度或与现有代理方案相似不能替代证据。

## 稳定状态与安全项目退出

可替换项目代码位于 `/jffs/home-edge-bootstrap`；保留的操作者与恢复状态位于
`/jffs/home-edge-bootstrap-state`。部署、回滚和项目退出都会保留稳定状态。项目退出默认先生成
计划，只删除经审查的项目辅助脚本、精确注册、经过校验的 kit 变体和默认可再生缓存；它不会
删除订阅、本地策略、恢复备份、Asuswrt-Merlin 固件或外部 ShellCrash/Mihomo 运行时。准确命令见
[快速开始](QUICKSTART.zh-CN.md)。运行时卸载和固件恢复仍是彼此独立的维护者/厂商操作。

下载时从 [GitHub Releases](https://github.com/yiheng8023/home-edge-bootstrap-public/releases)

发布物。互联网下载只能作为可选准备来源，不能成为必需恢复步骤。

## 安全与人工边界

- 自行核验 SSH 主机密钥；不要关闭主机密钥检查。
- 测试网关变更时，保留独立管理或恢复路径。
- 输入 `APPLY` 前，审查 dry-run 目标、路径、备份与回滚命令。
- 只有理解 dry-run 和回退行为后，才开启真实自愈；该写入需要精确令牌 `ENABLE`。
- 订阅 URL 属于凭据。绝不能提交到仓库、粘贴到 issue 或放入支持归档。
- 分享脱敏支持包前，逐个检查其中的文件。
- 不要把 fixture 成功、品牌知名度或单个目标成功扩展为更宽泛的兼容性声明。

对于账号、支付、注册及其他身份敏感操作，普通连通性或最低延迟出口不能证明出口身份稳定、
适用。自动选路与自愈可能在多次尝试之间改变出口。本项目可以暴露并约束这一连续性边界，
但不承诺平台接受、地区资格或交易成功。

6. 只有输入 `APPLY` 后才应用，并保留报告的备份。
7. 通过文档定义且不暴露敏感信息的路径提供订阅。
8. 验证运行时、路由器与客户端拓扑。
9. 自愈 dry-run 证据可接受后，再开启真实自愈。
10. 运行最终安装门禁，并保留恢复所需的非秘密证据。

任何阶段不能建立所需证据时，都应停在该边界，不得把证据缺失改写成接受结论。

## 订阅刷新与面板默认值

当前源码新增可选的周期与按需节点更新：每五分钟检查，正常每天获取一次；可用率连续
三次明显下降时可提前刷新，但须通过上网、冷却和退避检查。内容未变不重载；有变化时
保留本地规则、策略组和手动选择，先隔离验证，再取得不强制重建监听器的同步重载确认，
网络验证失败自动回退。订阅删除手动选中节点时报告冲突，不静默换选择。

Yacd-meta 初始默认：延迟从小到大、隐藏不可用节点、关闭自动断开旧连接；已保存的
浏览器选择优先。解析桥在操作电脑编译，路由器不安装 Go。
本地面板自动连接所在路由器：首次只填面板访问密钥，同一浏览器再次打开直接进入，
无需 Add 或选择 IP。控制器认证保持开启；固定使用同一地址并保留网站存储。
详见[订阅自动化](docs/SUBSCRIPTION_AUTOMATION.md)。已发布 v0.1.4 下载包不会追溯包含
这个源码功能；本站点验证与离线夹具证据分开，不扩大为全部固件或供应方的支持声明。

最新 v0.1.8 发行包含上述源码及 helper，Mihomo 离线载荷固定为 v1.19.32。
节点订阅自动更新仍需宿主编译 yamlbridge（可信网络或预备模块缓存），包内没有预编译 parser；
HTTPS 订阅、controller key、本地组过滤和站点显式启用是独立前提。详见[发布说明](docs/zh-CN/RELEASE_NOTES.md)。

OpenAI 的登录、会话与依赖域名需要一致的服务策略。普通延迟测试和服务商 [AI] 标签不能证明服务可用。请依照[服务规则步骤](docs/zh-CN/RUNBOOK.md)保留已验证的手动选择，分别核验持久规则与运行规则后再确认修复完成。
